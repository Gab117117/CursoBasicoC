C# desde cero;

Cuatro ideas para empezar a programar. Cambia los valores, pulsa los botones y mira qué pasa dentro del programa.

Variables: cajas con nombre

Una variable es una caja en la memoria. Tiene un tipo (qué cabe dentro), un nombre y un valor.

int edad = 15;

La memoria está vacía. Guarda tu primera variable.

Prueba: escribe un int con valor 3.5 y mira el error. Luego guarda otra variable con el mismo nombre para cambiar su valor.

if / else: elegir un camino

El programa evalúa una condición. Si es verdadera sigue un camino; si no, sigue el otro.

int edad = 16;if (edad >= 18)    Console.WriteLine("Puedes entrar");else    Console.WriteLine("Aún no puedes entrar");

Mueve el deslizador y cambia el operador. Fíjate en el cuidado con == (comparar) y = (asignar).

for: repetir sin copiar y pegar

Un bucle ejecuta el mismo bloque varias veces. Aquí cada casilla es una vuelta.

i = –
for (int i = 0; i < 5; i++){    Console.WriteLine("Vuelta " + i);}

Fíjate: i empieza en 0 y el bucle se detiene cuando i < n deja de cumplirse, por eso n vueltas van de 0 a n-1.
